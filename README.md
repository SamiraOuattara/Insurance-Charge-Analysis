# Insurance Charges Analysis

Which factors drive health insurance charges? Exploratory analysis, correlations,
a log-linear regression, and a Gamma GLM, all in R.

**Key finding:** smoking is the biggest driver (smokers pay about 4.5x more),
followed by children, age, and BMI.

## Files
- `insurance_analysis_v2.Rmd`: full analysis
- `insurance_analysis_v2.pdf`: knitted report
- `insurance.csv`: data

## Run it
Open the Rmd in RStudio, install dplyr, readr, ggplot2, and click Knit.
